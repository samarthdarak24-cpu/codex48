# PRECEDENT — Product Roadmap

---

## Phase 1: Completed Foundation (Current Release)
- Full 21-page architecture support (10 Creator + 11 Brand Manager features).
- Canonical `/api/v1` API catalogue with backward-compatible legacy aliases.
- 13 deterministic condition types in pure Python engine.
- A1 VisualGuard (OCR, CIE-Lab ΔE76 color difference, WCAG AA contrast).
- A2 Evidence Intelligence (passage chunking, hybrid search, strict citation validator).
- A3 Sentinel continuous post-publication monitoring and idempotent task generation.
- 5-agent bounded Review Crew.
- 50 passing automated tests in pytest.

---

## Phase 2: Near-Term Enhancements
- Integration of GPU-accelerated video frame analysis for TikTok and YouTube creative assets.
- Production pgvector HNSW indexing deployment on AWS RDS PostgreSQL.
- Presidio enterprise PII redaction pipeline with multi-language entity models.
- ProofPass: cryptographic Ed25519 digital signature certificates embedded into exportable PDF and PNG metadata.

---

## Phase 3: Long-Term Horizon
- Multi-brand enterprise hierarchy (Parent Corporation -> Sub-brands -> Regional Franchises).
- Real-time social media ad-network API connectors (Meta Marketing API, Google Ads API) for automated compliance ingestion prior to ad campaign launch.
